# Ta Hora

Site estático gerado pelo Builder. Roda sozinho, sem depender do builder.

## Como rodar

```bash
npm install
npm run build
```

O build gera a pasta `out/` com o site estático — hospede em qualquer lugar
(Netlify, Vercel, GitHub Pages, ou abrindo os arquivos num servidor estático).

Para desenvolvimento local:

```bash
npm run dev
```
